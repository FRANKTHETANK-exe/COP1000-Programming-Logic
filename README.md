# COP1000 Programming Logic

Python programs, flowcharts, and pseudocode for COP1000.

| Project | Description |
| --- | --- |
| [CarFinder](CarFinder/) | Menu-driven vehicle list with search, add, delete, and file storage. |
| [Payroll](Assignment2-4-Payroll/) | Calculates withholding and take-home pay. |
| [Admissions](Assignment3-2-Admissions/) | Applies test-score and class-rank conditions. |
| [Date Validation](Assignment3-3-DateValidation/) | Checks the ranges of a year, month, and day. |
| [Employee Bonus](Assignment4-2-EmployeeBonus/) | Calculates a bonus from shift and transaction data. |
| [Sign Pricing](SignPricing/) | Prices a sign by character count, wood, and lettering color. |
| [Age Calculator](AgeCalculator/) | Calculates an example age in 2050. |
| [Python Output](PythonOutput/) | Basic console output. |
| [School Commute](SchoolCommute/) | Flowchart and pseudocode for a commute. |
| [Value Multiplier](ValueMultiplier/) | Flowchart and pseudocode for multiplying a value. |

## Run

Requires Python 3. Run an exercise from the repository root:

```sh
python3 Assignment3-3-DateValidation/main.py
```

CarFinder has separate [run instructions](CarFinder/README.md).
